# الهندسة المعمارية

## دورة الطلب

يبدأ العميل بطلب JSON عبر CLI أو خادم `stdio`. يحدد `Policy` ما إذا كان الطلب في وضع التخطيط أو البناء، ثم يتحقق `ToolRuntime` من أن المسار داخل جذر مساحة العمل وأن الأداة ضمن مجموعة الأدوات المحدودة. بعد تنفيذ الأداة، تُعاد نتيجة مقتضبة ومحدودة الحجم إلى العميل، ويمكن تخزين الرسالة في SQLite.

```text
Client / TUI / MCP
        |
        v
Permission Policy ----> Plan: read/search only
        |
        +--------------> Build: write + allow-listed command
        |
        v
Tool Runtime ---> workspace files / subprocess / Termux:API
        |
        v
SQLite session store + Git snapshots
```

## قرارات السلامة

يُرفض اجتياز المسارات، وتُستبعد الروابط الرمزية عند الكتابة، وتُقص المخرجات الطويلة، ولا تُقبل أوامر الشبكة أو الحذف أو رفع الصلاحيات. وضع التخطيط هو الافتراضي حتى عند تشغيل خادم MCP. الانتقال إلى وضع البناء يحتاج إلى تشغيل مستقل مع `--mode build`، بينما تحتاج أوامر CLI إلى `--yes`.

## MCP والإفصاح التدريجي

لا تُرسل قائمة أدوات ضخمة؛ يعلن الخادم خمس أدوات فقط. تُعاد نتائج البحث على صورة `{path, line, text}`، وتُقرأ الملفات بحجم محدود، وتبقى البيانات الوسيطة داخل العملية. هذا النمط يقلل حجم السياق ويمنح العميل قدرة على طلب التفاصيل عند الحاجة.

## Termux وproot-distro

يبقى الخادم والواجهة في Termux لأفضل استجابة ممكنة، بينما تُستخدم Debian داخل `proot-distro` لمسارات البناء التي تحتاج إلى glibc أو حزم لينكس قياسية. لا يخلط المشروع بين بادئة Termux ومسارات FHS في Debian، ولا يحاول تثبيت `linux-headers-$(uname -r)` داخل Termux.

## الاستدلال المحلي

يُعد `scripts/build-llama-android.sh` مساراً اختيارياً لبناء llama.cpp لمعمارية `arm64-v8a` عبر Android NDK. يترك اختيار النموذج خارج المستودع، ويوصي بتنسيق GGUF وتكميم Q4_K_M وسياق محدود مثل 4096 رمزاً. لا تُضمّن أوزان النماذج أو مفاتيح المزودين في Git.

## GitHub Actions

تعتمد الأتمتة على إجراءات قابلة للمراجعة: الاختبارات عند التغيير، فحص TODO أسبوعي، تعليق مراجعة على طلبات السحب، وتصنيف أولي للقضايا. صلاحيات كل مهمة محدودة إلى `contents: read` مع `issues: write` أو `pull-requests: write` عند الحاجة. لا تُشغّل محتويات القضايا أو طلبات السحب كأوامر.
